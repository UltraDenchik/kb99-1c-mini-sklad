# Конфигурация 1С:Предприятие 8.3 — «Мини-Склад»

Учебная/демонстрационная конфигурация для ведения складского учета в управляемом приложении 1С:Предприятие.

Конфигурация выгружена в стандартном иерархическом XML-формате для версионирования в Git.

## 📂 Структура метаданных

### Подсистема «МиниСклад»:
* **Справочники:**
  * `Контрагенты` — справочник покупателей и поставщиков.
  * `Товары` — справочник товарных позиций.
* **Документы:**
  * `Поступление` — оприходование товара на склад от контрагента.
  * `Реализация` — отгрузка товара со склада контрагенту.

### Программный код (BSL):
* **Общий модуль `РаботаСФормамиКлиент`**:
  * Клиентский модуль для повторно используемой логики форм.
  * Метод `РассчитатьСумму(СтрокаТабличнойЧасти)` — динамический пересчет суммы строки ТЧ по формуле `Количество * Цена`.
* **Модули форм документов `Поступление` и `Реализация`**:
  * Обработчики событий таблицы формы `ТоварыКоличествоПриИзменении` и `ТоварыЦенаПриИзменении`.
  * Код структурирован стандартными директивами `#Область` согласно стандартам разработки 1С:ИТС.

## 🛠 Загрузка конфигурации в 1С:Предприятие

Для сборки конфигурации из исходников:

1. Откройте пустую информационную базу в режиме **Конфигуратор** (платформа 8.3.27 или выше).
2. В главном меню откройте дерево: **Конфигурация** → **Открыть конфигурацию**.
3. Выберите пункт меню: **Конфигурация** → **Загрузить конфигурацию из файлов...**
4. Укажите данную корневую папку репозитория.
5. Нажмите **Обновить конфигурацию базы данных** (клавиша `F7`).
